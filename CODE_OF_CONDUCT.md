# Code of Conduct – WebRadio Open Source Projekt

## 1. Ziel der Plattform
Dieses Projekt ist eine Open-Source WebRadio Plattform mit Plugin- und Theme-System. Ziel ist eine stabile, sichere und respektvolle Community.

---

## 2. Verhalten in der Community
Erwartet wird ein respektvoller Umgang miteinander.

Nicht erlaubt sind:
- Beleidigungen, Diskriminierung oder persönliche Angriffe
- Hassrede oder extremistische Inhalte
- gezielte Störung von Diskussionen oder Entwicklung
- Spam oder destruktives Verhalten

---

## 3. Inhalte und Nutzung
Es dürfen nur Inhalte verwendet werden, die:
- rechtlich zulässig sind
- keine Urheberrechte verletzen
- keine schädlichen oder illegalen Inhalte enthalten

---

## 4. Pluginsystem
Plugins müssen:

- ausschließlich über die offizielle API arbeiten
- keine Core-Komponenten direkt verändern
- im Sandbox-Modus laufen
- Fehler intern behandeln

Nicht erlaubt:
- Umgehung der Sandbox
- Zugriff auf interne Systemfunktionen
- unkontrollierte Hintergrundprozesse

---

## 5. Theme-System
Themes dürfen nur visuelle Änderungen vornehmen.

Erlaubt:
- Farben, Abstände, Layout
- CSS Variablen / Design Tokens

Nicht erlaubt:
- JavaScript Logik
- Netzwerkzugriffe
- Manipulation von App-Funktionalität

---

## 6. Sicherheit
Jegliche Form von Angriffen, Exploits oder Missbrauch ist untersagt.

---

## 7. Moderation
Bei Verstößen kann es zu folgenden Maßnahmen kommen:
- Verwarnung
- Deaktivierung von Plugins
- Sperrung von Accounts
- Entfernung von Beiträgen

---

## 8. Haftung
Keine Haftung für Inhalte von Drittanbietern oder Community-Plugins.

---

## 9. Änderungen
Dieser Code of Conduct kann jederzeit angepasst werden.
