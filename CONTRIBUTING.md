# Contributing

Die vollständige Anleitung zum Beitragen befindet sich in der Dokumentation:

➡️ **[docs/CONTRIBUTING.md](./docs/CONTRIBUTING.md)**

Issue-Vorlagen und Label-Empfehlungen sind im Repository unter `.github/ISSUE_TEMPLATE/` und `.github/labels/` (falls vorhanden) hinterlegt.

Wenn du das Projekt erstmals konfigurierst, sind folgende Workflow-Bestandteile bereits vorhanden:

- CI: `.github/workflows/ci.yml`
- Linux-Build: `.github/workflows/build-linux.yml`
- Plattform-Builds: `.github/workflows/build.yml`
- Release-Workflow: `.github/workflows/release.yml`
- Download-Statistiken: `.github/workflows/download-stats.yml`

Fehlende GitHub-Metadaten sind im Security-Policy-Text als Empfehlungen aufgeführt.

Issue-Kategorien sind über die Dateien in `.github/ISSUE_TEMPLATE/` vordefiniert.

Labels und Beitragsrichtlinien werden über GitHub konfiguriert, sobald das Repository auf GitHub bereitgestellt wird. Das Projekt verwendet bisher keine eigenen Label-Dateien im Repository.
